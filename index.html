    Công cụ hoạt động như thế nào?
    1. Chọn file: kéo thả, bấm để chọn hoặc dán (Ctrl/Cmd + V). Công cụ tự nhận loại file (ảnh JPG, PNG, WEBP, AVIF, GIF, BMP, SVG hoặc PDF) và hiện ở dòng "Đã nhận".
    2. Chọn loại muốn đổi sang:
      • WEBP / JPG / PNG / AVIF: ảnh đổi định dạng; file PDF thì mỗi trang thành 1 ảnh.
      • PDF: gộp tất cả ảnh (và cả file PDF) thành 1 file PDF khổ A4, theo thứ tự trong danh sách. Dùng nút ↑ ↓ để sắp xếp.
    3. Chọn chất lượng: "Mặc định" cân bằng dung lượng và độ nét. Sang trái file nhẹ hơn, sang phải nét hơn. PNG không áp dụng mức này.
    4. Tải về: tải từng file hoặc tải tất cả (ZIP). Khi đổi sang PDF thì bấm "Tải PDF".

    Bên trong: ảnh được vẽ lên canvas rồi xuất lại theo định dạng đã chọn. Trang PDF được vẽ thành ảnh bằng PDF.js. Gộp PDF dùng pdf-lib: ảnh đặt vừa khổ A4 (tự xoay ngang nếu ảnh ngang), trang PDF có sẵn được chép nguyên. Mọi thứ chạy trên máy bạn, file không được tải lên máy chủ nào. Khi đổi sang JPG hoặc PDF, vùng trong suốt thành nền trắng; GIF động chỉ lấy khung hình đầu.

    How does it work?
    1. Add files: drag and drop, click to choose, or paste (Ctrl/Cmd + V). The tool detects each file's type (JPG, PNG, WEBP, AVIF, GIF, BMP, SVG images or PDF) and lists it under "Detected".
    2. Pick what to convert to:
      • WEBP / JPG / PNG / AVIF: images change format; each PDF page becomes one image.
      • PDF: all images (and PDFs) are merged into one A4 PDF in list order. Use ↑ ↓ to reorder.
    3. Pick a quality: "Default" balances size and sharpness. Left is lighter, right is sharper. PNG ignores this setting.
    4. Download: one by one or all as a ZIP. For PDF, click "Download PDF".

    Under the hood: images are drawn onto a canvas and re-exported in the chosen format. PDF pages are rendered to images with PDF.js. Merging uses pdf-lib: images are fitted to A4 (landscape for wide images) and existing PDF pages are copied as-is. Everything runs on your device; nothing is uploaded. JPG and PDF output put transparent areas on white; animated GIFs keep only the first frame.
